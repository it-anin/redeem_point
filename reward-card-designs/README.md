# Cream Rewards — การ์ดรางวัล 20 แบบ

เปิด **index.html** เพื่อดูและเปรียบเทียบทั้ง 20 แบบ หรือเปิดไฟล์หมายเลข 01–20 เพื่อดูแต่ละดีไซน์

- โทนเดียวกับ UI ปัจจุบัน: ครีม `#FFF3EC`, พีช `#FBD3B9`, ขอบ `#F6D8C5`, น้ำตาล `#A85A2E`
- ฟอนต์ Itim + Nunito ตรงกับฝั่งพนักงานในโปรเจกต์
- แต่ละไฟล์ HTML มี CSS, JavaScript และภาพ SVG ฝังในไฟล์ เปิดโดยดับเบิลคลิกได้ ไม่ต้องติดตั้งหรือรันเซิร์ฟเวอร์
- ฟอนต์ Google Fonts โหลดเมื่อมีอินเทอร์เน็ต หากออฟไลน์จะใช้ Tahoma/ฟอนต์ระบบแทน
- ทุกแบบมีตัวอย่างรางวัลพิเศษ (Gift Card) และรางวัลปกติ (ค่าอาหาร)
- เปลี่ยนดูได้ 5 สถานะ: พร้อมแลก, รอเปิดแลก, หมดแล้ว, แต้มไม่พอ, งดแลกชั่วคราว
- กำหนดรอบเปิดแลกเป็นข้อความตัวอย่าง 15/11 เวลา 10:38 น. ไม่มีการนับถอยหลังหรือเชื่อมต่อฐานข้อมูล
- หน้ารวมกรองหมวด กดหัวใจเก็บแบบที่ชอบในเบราว์เซอร์ และเปิดแต่ละแบบได้
- หน้าแยกปรับความกว้างการ์ด 174 / 196 / 220px ได้ โดยย่อให้พอดีจอมือถืออัตโนมัติ
- ปุ่มแลกรางวัลเปิดหน้าต่างตัวอย่าง ไม่มีการหักแต้ม จองรางวัล หรือเขียนข้อมูลไปยังระบบจริง
- ภาพบัตรของขวัญและอาหารเป็นภาพเวกเตอร์จำลองสำหรับเปรียบเทียบดีไซน์ เปลี่ยนเป็นรูปสินค้าจริงได้ภายหลัง

## สร้างไฟล์ซ้ำ

แก้ไข `build.cjs` แล้วรันจากโฟลเดอร์โปรเจกต์:

```sh
node reward-card-designs/build.cjs
```

โฟลเดอร์นี้แยกจากแอป React เดิม ไม่ต้องใช้ Firebase และไม่มีขั้นตอน deploy

## มาสคอตในป๊อปอัป

- ใช้รูปต้นฉบับ `public/iconcry.png` และ `public/iconlol.png` ฝังเป็น PNG ใน HTML ทุกไฟล์ จึงเปิดไฟล์แยกได้โดยไม่ต้องคัดลอกโฟลเดอร์รูป
- เลือกสถานะ **แต้มไม่พอ** แล้วกดปุ่มแลกรางวัล จะเห็น `iconcry` พร้อมข้อความ “แต้มไม่พอ!” และปุ่ม “ไปทำงานก่อน”
- เลือกสถานะ **หมดแล้ว** แล้วกดปุ่ม “หมดแล้ว” จะเห็น `iconlol` พร้อมข้อความ “ไม่ทันจ้า! มีคนตัดหน้า” และปุ่ม “รอรอบหน้า”
- ขนาดภาพ 150 × 150 พิกเซล กรอบป๊อปอัปและข้อความใช้รูปแบบเดียวกับแอปเดิม
- สถานะรอเปิดแลกและงดแลกชั่วคราวยังปิดการกดปุ่มตามเดิม
- หากสร้างไฟล์ใหม่ด้วย `build.cjs` ให้รันภายในโปรเจกต์เดิมที่มีรูปต้นฉบับใน `public/`
